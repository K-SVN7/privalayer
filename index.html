À propos

PrivaLayer chiffre localement, dans votre navigateur, avant que quoi que ce soit ne quitte l'appareil. Aucun serveur, aucune télémétrie, zéro requête réseau.

Code source sur GitHub

Version 2.0.0

Bienvenue sur PrivaLayer

Vos messages et fichiers sont chiffrés sur votre appareil avant d'être envoyés. Personne ne peut les lire, même pas nous.

Comment ça marche

Échangez vos clés publiques avec un ami
Chiffrez votre message ou fichier
Envoyez-le par n'importe quel canal

Seul votre destinataire peut déchiffrer.

Échanger les clés

Allez dans Ma clé, copiez votre clé publique et envoyez-la à votre contact. Demandez-lui de faire pareil. C'est une seule fois par contact.

100% local

Aucun serveur, aucun compte, tout tourne sur votre appareil. Même hors connexion.

Installer sur l'écran d'accueil

iPhone

Ouvrez dans Safari → Appuyez sur le bouton Partager (carré avec flèche) → Sur l'écran d'accueil

Samsung / Android

Ouvrez dans Chrome → Menu ⋮ → Ajouter à l'écran d'accueil

Sans ça, vos clés seront perdues si vous videz le cache du navigateur.
